API Documentation
API Overview

RESTful API endpoints for accessing basin data and time series information. All endpoints return JSON data. Use the "Test" buttons to try each endpoint, or copy the URLs to use in your own applications.

Available Endpoints
1. List All Basins

GET /api/basins/

Returns a list of all imported basins with their metadata.

2. Get Basin Details

GET /api/basins/{basin_id}/

Returns detailed information about a specific basin including column mappings and statistics.

Basin ID:
3. Get Basin Wells

GET /api/basins/{basin_id}/wells/

Returns all wells in a basin with their measurement counts and coordinates.

Query Parameters: min_measurements (optional, default: 1)

Basin ID: Min Measurements:
4. Get Well Time Series

GET /api/basins/{basin_id}/wells/{well_id}/timeseries/

Returns time series data for a specific well.

Query Parameters: start_date, end_date (optional)

Basin ID: Well ID:
5. Get Basin Statistics

GET /api/basins/{basin_id}/statistics/

Returns comprehensive statistics about a basin including well counts, measurement distributions, and date ranges.

Basin ID:
6. Query Basin Data

POST /api/basins/{basin_id}/query/

Query basin data with filters. Supports filtering by date range, well IDs, and value ranges.

Body: {"well_ids": [1,2,3], "start_date": "2020-01-01", "end_date": "2023-12-31", "limit": 100}

Basin ID:
7. List All Schemes

GET /api/schemes/

Returns all column mapping schemes with their column definitions.
